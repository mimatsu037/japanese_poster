01

チャッピーにアイデア出しをお願いする

海外の方が「日本っぽい！」と感じるモチーフの例はこんな感じ🌸

  • ・京都の街並み × 桜
  • ・電車 × 富士山
  • ・日本庭園 × 紅葉

こういったテーマを、チャッピーに12案まとめて考えてもらいます。

【コピペ用プロンプト】

これから海外のお客様向けにデジタルポスターを販売しようと思っています。 「日本」を感じさせるポスターのデザイン案を12個、一緒に考えてください。 見た人が「これは日本だ」「行ってみたい」「部屋に飾りたい」と直感的に感じられるようなアイデアがほしいです。 # アイデアを考えるときの条件 ・パッと見て日本らしさが伝わるモチーフを選ぶこと ・海外の人にも理解しやすいモチーフにすること ・部屋のインテリアとして違和感なく飾れるデザインにすること ・12案の間で構図や雰囲気がなるべく重複しないこと ・都市／自然／季節／乗り物／食文化／伝統文化といったジャンルをまんべんなく散りばめること ・候補地は京都・東京だけに偏らせず、日本各地から選ぶこと ・画像生成AIで再現しやすい、イメージしやすい内容にすること ・存在しない日本語表記や看板が写り込みにくい構図を意識すること # 各案でまとめてほしい情報 1. テーマの名前（例：桜舞う京都と赤い電車） 2. 中心となる場所・モチーフ（例：古都の街並み、桜、赤い電車） 3. 構図のイメージ（例：手前に桜を配置し、中央を電車が横切り、奥に山並みが見える構図） 4. 雰囲気・テイストの提案（例：昭和レトロ調、ヴィンテージトラベルポスター、和モダン、水彩タッチなど） 5. 配色の提案（例：淡いピンク、生成り色、朱色、くすみグリーン） # バリエーションについて かわいらしい雰囲気・レトロな雰囲気・ミニマルな雰囲気・和モダン・幻想的・旅行ポスター風など、テイストに幅を持たせて提案してください。 # 最後にお願いしたいこと 出した12案のうち、海外向けデジタルポスターとして特に相性が良さそうな3案をピックアップし、その理由も簡潔に教えてください。 なお、「レトロ感をもっと強めて」「女性ウケしそうな雰囲気にして」「京都だけで12案考えて」のように、あとから追加で条件を伝えて調整してもらうこともできます。

02

ポスター画像を作ってもらう

決まったテーマを使って、実際にポスター画像を生成してもらいます。 世界観や構図の条件を伝えるほど、仕上がりの質が上がります🖼️

【コピペ用プロンプト】

# やってほしいこと さきほど考えてもらった日本風ポスター案の中から、次の3案を使って、海外の20〜30代女性が「部屋に飾りたい」と思うようなポスター画像を作成してください。 # 今回使う3案 【ここに1案目を貼る】 【ここに2案目を貼る】 【ここに3案目を貼る】 各案について、さきほど出してもらった場所・モチーフ・構図・テイスト・配色の情報をなるべく反映してください。 # 想定している購入者 ・日本文化や日本旅行に興味がある海外の20〜30代女性 ・温かみのあるおしゃれなインテリアを好む人 ・寝室やリビング、仕事部屋に飾れるアートを探している人 # 全体のトーン ・日本の風景を描いた、レトロで上品な旅行ポスター風の仕上がり ・淡いピンクや朱色、生成り色、パステルブルーを基調にすること ・紙のような質感を少し加え、温かみを出すこと ・海外のインテリアにもなじむ、洗練された配色にすること ・3枚並べたときに統一感が出るようにすること ・3枚とも画風・色味・質感は揃えつつ、構図はそれぞれ変えること ・実在の写真の再現ではなく、オリジナルの構図で描くこと ・写実的になりすぎず、アートとして飾りやすい表現にすること # デザインで意識してほしいポイント ・主役のモチーフがひと目でわかること ・情報を詰め込みすぎず、余白を活かした構図にすること ・遠くから見ても印象に残ること ・海外の人が見て「日本らしい」と感じられること ・日本人が見ても文化的・地理的な違和感がないこと # 日本らしさを描くうえでの注意点 ・建物、電車、鳥居、提灯、着物などは日本文化として自然な形にすること ・中国風・韓国風の建築や衣装、装飾と混同しないこと ・地理的にありえない風景の組み合わせは避けること ・鳥居や畳、日本家屋の形・配置に違和感がないようにすること ・人物を描く場合は小さな後ろ姿や遠景程度に留めること ・季節を表す場合は、植物・服装・空の色も季節に合わせること # 避けてほしいこと ・ポスター内に日本語、英語、数字、ロゴ、サイン、透かしを入れないこと ・意味を持たない日本語風の文字や模様を入れないこと ・実在のブランドロゴを使わないこと ・既存のキャラクターや作品、特定作家の画風を模倣しないこと ・顔や手が大きく写る人物を配置しないこと ・写真と見紛うようなリアルすぎる表現にしないこと ・3枚が似たような構図にならないようにすること # 出力の形式 ・3枚を横並び、または均等に配置した一覧画像として出力すること ・後で1枚ずつ切り出せるよう、ポスターの間に十分な余白を空けること ・各ポスターは縦長の3:4比率で、サイズ・縦横比を3枚とも揃えること ・番号や文字は入れないこと ・完成した一覧画像だけをそのまま出力すること
